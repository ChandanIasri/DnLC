
# Software Dependencies

The software utilizes a diverse set of Python packages to ensure smooth operation, data handling, visualization, machine learning, and GUI development. Core packages include **`numpy==2.2.4`**, **`pandas==2.2.3`**, and **`scikit-learn==1.6.1`** for data processing and modeling, along with **`matplotlib==3.10.1`** and **`seaborn==0.13.2`** for visualizations. GUI components are handled through **`customtkinter==5.2.2`** and **`darkdetect==0.8.0`**, while **`pyinstaller==6.13.0`** and its companion **`pyinstaller-hooks-contrib==2025.3`** enable application packaging. Image processing and deep learning functionalities are supported by **`opencv-python==4.11.0.86`**, **`torch==2.6.0`**, and **`torchvision==0.21.0`**. Utility and environment-specific packages include **`filelock==3.18.0`**, **`psutil==7.0.0`**, **`requests==2.32.3`**, and **`tqdm==4.67.1`**, among others. Additional dependencies such as **`Jinja2==3.1.6`**, **`joblib==1.4.2`**, **`sympy==1.13.1`**, and **`networkx==3.4.2`** contribute to extended computational and templating functionalities. Altogether, the project integrates over 45 packages, explicitly specified with versions to ensure reproducibility and compatibility across systems.
